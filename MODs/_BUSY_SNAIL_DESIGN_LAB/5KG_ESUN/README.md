# Busy Snail Filament Changer (BSFC) Roller Tray And Spool Controller for eSun <ins> 5kg Spool Mod </ins> by Busy Snail Design Lab
This mod has been tested and used with the eSun 5kg spool (d=300mm, w=160mm). It should also work with other brands using this standard off-the-shelf spool size, though this has not been confirmed.
